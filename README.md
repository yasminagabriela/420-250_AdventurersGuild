# AdventurerGuild_turnbased_RPG
Un turn-based RPG dans un 2D top down, Plusieurs aventuriers cherchent à battre le boss final. Mais pour s’y rendre, tu dois te battre avec des ennemis sournois qui peuvent te tuer ou te donner accès au prochain niveau. Public visé sont pour tous. (Violence fictive et visuels simples)
